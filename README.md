Simple Fire Emblem clon prototype (tactical turn-based RPG) made in LUA using the Löve Framework. Meant as an exercise to try to learn the library.

Game implements a simple GUI, sprite display and the movement system for the units, with a simple pathfinder algorithm to look for all possible squares a unit can move based on each of the tile's cost.
